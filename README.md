# m.

someone used to keep notes here. they've taken them down.

that's about all i'll say. **m.** is a small puzzle dressed up as an abandoned homepage from 2019. no instructions, no timer, no score. just a quiet page and whatever you happen to notice about it.

**start here → [m.asalkc.com.np](https://m.asalkc.com.np)**

a few things, before you go:

- take your time. it rewards curiosity more than cleverness.
- you don't need to be technical. knowing your way around a browser helps in places, but everything can be found by reading carefully and poking around.
- it works on a phone, but a laptop at night is nicer.
- nothing you do leaves your browser. no accounts, no analytics, no tracking.
- stuck? that's part of it. close the tab, make some tea, come back tomorrow.

## please don't spoil it

if you reach the end, keep it to yourself and send the link to a friend instead. the code is all here, but the ending is sealed, so reading the source won't get you there any faster than playing. it's more fun the other way round.

## running it yourself

```bash
python3 -m http.server 8765 --directory docs
```

then open http://localhost:8765. the last door only opens over https or localhost, so opening the files straight from your disk won't work.

## ai usage

Mostly debugging and pretty much all of the styling. Piloted the styling. Also used it to add comments and clean up the code so it's easier to read and makes more sense.
